# Audit Advisor — русская версия для своего сервера

11 стандартов, 505 вопросов, 1010 примеров. Комплект от 5 ноября 2026 года.

## Состав

- frontend/tilda-t123.txt — код одного блока T123; сначала укажите адрес своего сервера.
- frontend/tilda-t123.template.html — шаблон с одним заполнителем __SET_HOSTING_URL__.
- server/ — готовая серверная часть: JavaScript, JSON с вопросами и проверочная HTML-страница.
- source/ — полные редактируемые исходники этой языковой версии и средства сборки.
- server-config/ — примеры заголовков для Nginx и Apache.
- configure.py — настройка адреса без Node.js и сторонних Python-библиотек.

Программа выполняется в браузере. Сервер отдаёт статические файлы; база данных, PHP, Node.js-сервис и Firebase SDK для работы не нужны. Ответы остаются в браузере посетителя. Node.js нужен только при пересборке исходников.

## Установка

1. Загрузите **содержимое server/** в отдельный публичный каталог вашего HTTPS-сервера. Не загружайте весь архив в публичный каталог.
2. Настройте CORS и кэш по server-config/. Проверьте типы файлов: JavaScript для .js и application/json для .json. Отсутствующие JSON должны возвращать 404.
3. В корне распакованного комплекта выполните, подставив реальный публичный адрес каталога, куда загружены файлы:

```sh
python3 configure.py https://YOUR_DOMAIN/PUBLIC_DIRECTORY/
```

Например, если каталогом размещения выбран /tools/readiness-ru/, адрес должен заканчиваться именно на /tools/readiness-ru/. Адрес указывает на каталог, где лежит audit-advisor.js, а не на файл index.html.

4. Откройте frontend/tilda-t123.txt, скопируйте весь текст в один T123 русской страницы Тильды и опубликуйте её.
5. Откройте опубликованную страницу, выберите один стандарт и проверьте первый вопрос.

Если Python недоступен, в frontend/tilda-t123.txt вручную замените единственное __SET_HOSTING_URL__ на тот же HTTPS-адрес каталога. Пока адрес не задан, блок явно сообщает о необходимости настройки.

server/index.html использует относительный адрес файлов и подходит для проверки сразу после загрузки. У него сохранён noindex: основной сценарий установки — блок на Тильде. Оба языка можно держать на одном сервере в разных каталогах; каждый T123 должен ссылаться на свой каталог.

## Изменение текстов и пересборка

Редактируйте source/content/interface.ru.json и source/content/standards/*.json. Heading — заголовок, description — абзацы, examples — примеры, condition — примечание. Для поиска вопроса используйте ID стандарта и вопроса. Сохраняйте ID, значения ответов, answerVersion, веса, разделы и правила применимости при стилистической правке; изменяйте contentRevision. Подписи ответов находятся в answerPresets, индивидуальные замены — в answers.overrides.

```sh
cd source
npm install
npm run check:content
npm run build
```

Сборка обновляет ../server/ и ../frontend/, используя адрес из ../hosting.json. После изменения вопросов загрузите обновлённые серверные файлы. После изменения вводного заголовка, оформления или загрузчика также обновите T123. server/.htaccess можно использовать на Apache; файл server-config/nginx-headers.conf — фрагмент для действующей конфигурации Nginx. Настройки HTTPS и корневого каталога остаются в конфигурации вашего сервера.

Историческая основа вопросников и ограничения сохранены в JSON. Этот комплект переносит существующую программу; новые критерии оценки не добавлялись. PACKAGE.json содержит сведения о комплекте и хеш JavaScript. Сейчас адрес вашего сервера намеренно не задан: настройте его перед установкой.
